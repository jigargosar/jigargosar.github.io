Shift+Enter Not Working in Claude Code: The Fix

DATE: 2026.02.17 | READ: 3 MIN | TYPE: TIL

If you've been fighting with Shift+Enter in Claude Code on Windows, here's your escape hatch. The default keybinding treats it as a submit action instead of a newline.

■ THE PROBLEM

Claude Code's terminal input captures Shift+Enter and fires it as a submission. For developers writing multi-line prompts, this breaks the expected workflow completely.

■ THE SOLUTION

Override the keybinding in your configuration:

{
  "keybindings": {
    "shift+enter": "newline",
    "enter": "submit"
  }
}
Tools should match your muscle memory, not fight against it.

■ CHECKLIST

  • Check terminal emulator settings for key interception
  • Restart Claude Code after config changes
  • Test with multi-line code block paste
