Shift+Enter Not Working in Claude Code: The Fix

2026-02-17 3 min read til

If you've been banging your head against the wall trying to get Shift+Enter to create a newline in Claude Code on Windows, you're not alone.

The Problem

Claude Code's terminal input captures Shift+Enter as a submit action instead of inserting a newline.

The Solution

{
  "keybindings": {
    "shift+enter": "newline",
    "enter": "submit"
  }
}
The best tools get out of your way.
  • Check your terminal emulator settings too
  • Restart Claude Code after making changes
  • Verify with a multi-line code block paste
