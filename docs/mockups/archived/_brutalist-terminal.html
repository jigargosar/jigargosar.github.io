Shift+Enter Not Working in Claude Code: The Fix

2026-02-17 3 min read TIL

If you've been banging your head against the wall trying to get Shift+Enter to create a newline in Claude Code on Windows, you're not alone. Here's the quick fix.

The Problem

Claude Code's terminal input captures Shift+Enter as a submit action instead of inserting a newline. This makes writing multi-line prompts painful.

The Solution

The fix involves updating your keybindings configuration. Open your settings and add the following override:

{
  "keybindings": {
    "shift+enter": "newline",
    "enter": "submit"
  }
}

Why This Happens

The default keybinding map treats both Enter and Shift+Enter as submission triggers. This is a holdover from chat-style interfaces where multi-line input isn't the norm.

The best tools get out of your way. A keybinding that fights your muscle memory is a tool that's in the way.
  • Check your terminal emulator settings too — some intercept the key combo
  • Restart Claude Code after making changes
  • Verify with a multi-line code block paste
