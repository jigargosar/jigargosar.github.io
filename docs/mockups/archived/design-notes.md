# Blog Design Notes

## Direction
Minimal developer. Spacing creates structure — not lines, not borders. Monochrome chrome, neon cyberpunk hero images provide the color contrast.

## Winning Direction: 09-minimal-developer (refined in 10a/10c)
- Closest to the right feel
- Paint stroke accent under title — signature element
- Spacing-only structure, no lines
- Slim hero image (3:1), not dominant
- Softer bg (#111114) + dimmer fg — less contrast than #09's pure black
- Reference mockups: 10a (Instrument Sans), 10c (DM Sans)

## Personality
- Developer, not journalist
- Confident, not fancy
- Monochrome with a dash of color — permanent, non-animated

## Color / Contrast
- Foreground colors too bright against pure black — needs softer bg or dimmer fg
- Hero images will be full neon cyberpunk glow — the chrome must contrast with that
- Muted monochrome layout + vivid neon hero images = intentional contrast
- The blog chrome should be quiet so the hero images pop

## Likes
- **09-minimal-developer**: Overall direction — spacing, paint stroke, developer sans-serif
- **06-dark-glass-mono**: Hero image treatment — desaturated, dimmed
- **07-editorial-glass-hybrid**: Side-by-side layout
- Spacing-driven hierarchy — whitespace defines sections
- Paint stroke as signature element (below title, static)

## Dislikes
- Neon colors in the chrome/layout — too over the top (save neon for hero images only)
- Warm/gold accents — wrong tone
- Overly glassy effects
- Hero image dominating content
- Parallax/motion effects — not worth it
- Editorial/magazine aesthetic — drop caps, pullquotes, serif luxury
- Lines and borders as structural dividers
- Foreground text too bright on pure black

## Hero Image
- Should not dominate layout — supports content
- Will be neon cyberpunk style — vivid, glowing
- Layout must contrast: quiet monochrome chrome, loud hero image
- Slim aspect ratio (3:1) or side-by-side
- No parallax, no desaturation needed (images are already stylized)

## Typography (decided)
- Headings/nav: **Instrument Sans** (700) — clean, developer, distinctive
- Body text: **Source Serif 4** (300/400) — excellent readability on dark bg, restrained serif
- Code/meta/dates/tags: **JetBrains Mono**
- Rejected: DM Sans (too common), Geist (Vercel-associated), Playfair Display (too editorial)

## Palette
- Background: not pure black — slightly warmer/softer dark
- Foreground: dimmer grays, less contrast with background
- One dash of color: paint stroke accent
- Hero images provide all the color

## Layout
- Spacing defines structure, no lines
- Generous whitespace between sections
- Glass: minimal, only for code blocks and bonus cards

## Decisions Pending
- Paint stroke hue: match blog accent theme or fixed?
- Hero aspect ratio: 3:1 vs 2.5:1?
- Exact contrast values: tune in browser devtools on live site
