Shift+Enter Not Working in Claude Code

A quick fix for a small annoyance that wastes big chunks of time

Jigar Gosar · February 17, 2026 · 3 min read

If you've spent any time with Claude Code on Windows, you've probably discovered that Shift+Enter doesn't insert a newline. Instead, it submits your prompt.

This is one of those paper-cut issues that seems trivial until you realize how much time you lose wrestling with it across a full workday.

The Root Cause

Claude Code inherits keybinding defaults from a chat-oriented paradigm where Enter means "send." The assumption is single-line input. For developers writing multi-line prompts with code blocks, this breaks down immediately.

The best developer tools match your existing mental model, not force you to build a new one.

The Fix

Open your keybindings configuration and add the following override:

{
  "keybindings": {
    "shift+enter": "newline",
    "enter": "submit"
  }
}
  • Check your terminal emulator settings too — some intercept the key combo
  • Restart Claude Code after making changes
  • Verify with a multi-line code block paste
